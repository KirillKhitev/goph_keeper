# Менеджер паролей GophKeeper

Клиент-серверная система, позволяющую пользователю надёжно и безопасно хранить логины, пароли, файлы и прочую приватную информацию.

## Типы хранимой информации
* пары логин / пароль;
* произвольные текстовые данные;
* произвольные бинарные данные (файлы, изображения и пр.) произвольного размера;
* данные банковских карт.

## Возможности
* Клиент имеет TUI-интерфейс
* Возможность запуска Клиента на платформах Windows, Linux и Mac OS
* Система авторизации
* Пользовательские данные не хранятся на сервере в незашифрованном виде
* Никто кроме пользователя не может расшифровать данные

## Тестирование
Код покрыт unit-тестами более чем на 80%
